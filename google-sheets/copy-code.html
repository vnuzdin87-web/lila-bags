Код для Google Apps Script

Скопируйте код кнопкой — так в него не попадут лишние символы и не потеряются переносы строк.

  1. Откройте свою Google Таблицу → Расширения → Apps Script.
  2. В файле Код.gs нажмите Ctrl+A, затем Delete — поле должно стать полностью пустым.
  3. Нажмите кнопку «Скопировать код» ниже, вернитесь в редактор и вставьте: Ctrl+V (лучше «вставить без форматирования»: Ctrl+Shift+V).
  4. Сохраните: Ctrl+S.
  5. Выберите функцию setup и нажмите Выполнить — разрешите доступ.
