# AGENTS.md — правила работы над сайтом LILA

## Что это за сайт

- Одностраничный лендинг мастерской **LILA** — индивидуальный пошив сумок и аксессуаров из натуральной кожи.
- Сделан по образцу <https://irinastepovaya.com/>: светлый минимализм, сиреневый градиент, «стеклянные» карточки, мягкие появления блоков при скролле.
- Город в текстах: Санкт-Петербург.
- Цель страницы одна: **получить заявку** (форма в блоке «Запись») — плюс прогреть человека до этого через блоки «боль → эксклюзивность → качество → процесс → работы → отзывы».

## Для кого

- Женщины 25–45 лет, которым надоели сумки «на один сезон» и которые готовы платить за вещь ручной работы под себя.
- Тон общения — на «вы», спокойный, без агрессивных продаж и восклицаний.

## Из чего состоит проект

| Файл | Что внутри |
|---|---|
| `index.html` | Весь контент и разметка страницы (одна страница, все секции). |
| `styles.css` | Все стили: шрифты, токены, компоненты, адаптив. |
| `script.js` | Вся логика: прелоадер, появление блоков, параллакс, меню, мини-конструктор, фильтр работ, **отправка формы**. |
| `assets/` | 19 фотографий, `assets/fonts/` — 7 файлов шрифтов, `favicon.svg`. |
| `google-sheets/Code.gs` | Код веб-приложения Google Apps Script, которое принимает заявки и пишет их в таблицу. |
| `google-sheets/README-google-sheets.md` | Инструкция по этой связке (связка уже настроена, см. блок «Уже настроено»). |
| `google-sheets/copy-code.html` | Вспомогательная страница для копирования `Code.gs`. Не обязательна. |
| `Screenshot*.png`, `Снимок*.png`, `Промпт*.docx` | Материалы заказчика и ТЗ. **Не удалять и не изменять.** |

Сборщика нет: сайт открывается как есть, файлы кладутся на любой хостинг.

## Стиль оформления

**Цвета** (переменные в `:root`, `styles.css`):

- фон `--bg #f7f3f9`, светлый `--bg-2 #fbf9fc`;
- текст `--ink #241c2e`, мягкий `--ink-soft #4b3f5c`, приглушённый `--muted #776a89`;
- сирень: `--lilac #8f6fd8`, светлая `--lilac-2 #b79bf0`, глубокая `--lilac-3 #6a45c0`, заливка `--lilac-soft #ece4fb`;
- стекло: `--glass rgba(255,255,255,.62)`, границы почти белые;
- тени — мягкие, сиреневые, без резких чёрных.

**Шрифты** (подключены локально, без CDN):

- `Cormorant Garamond` (serif) — заголовки, крупные цифры, курсивные акценты внутри заголовков (`<em>`);
- `Manrope` (sans) — весь остальной текст, кнопки, подписи.

**Общий вид и приёмы:**

- контейнер `1220px`, скругления 16/26/38px и «таблетки» 999px;
- размытые сиреневые пятна на фоне + лёгкое зерно;
- карточки-«стёкла» (полупрозрачный белый фон, blur, тонкая граница);
- появление блоков при скролле (`.reveal`), параллакс фото, лёгкий наклон карточек работ, счётчики, бегущая строка;
- крупные кнопки: основная (сиреневая), акцентная (для формы), призрачная;
- адаптив: 1080px, 900px, 640px; есть отдельные правила для `prefers-reduced-motion`.

## Блоки страницы по порядку

1. Прелоадер, фон-декор, шапка с полосой прогресса и меню, бургер на мобильном.
2. `#hero` — «Сумка, которая рассказывает вашу историю», лид, две кнопки, три счётчика.
3. Бегущая строка.
4. `#problem` — цитата «Устала выбрасывать сумки через сезон…», три боли, фото.
5. `#exclusive` — УТП «100% эксклюзивность…», абзац о соавторстве, мини-конструктор (модель, оттенок кожи, цвет строчки).
6. `#quality` — «Почему наши сумки служат годами»: срез кожи, шов, фурнитура.
7. `#process` — пять шагов работы.
8. `#works` — галерея 8 работ с фильтрами (все / тоут / кроссбоди / аксессуары).
9. `#reviews` — три отзыва.
10. `#contacts` — блок «Запись»: форма и контакты.
11. Подвал.

## Форма заявок

- Разметка: `index.html`, блок `#contacts` → `form#form`.
- Поля: `name` (имя), `contact` (телефон или Telegram), `wish` (что сшить, необязательно).
- Скрытое поле-ловушка `company` (`.hp`): люди его не видят, заполняют только боты — такая заявка молча отбрасывается.
- Проверка: имя и контакт обязательны и длиннее 2 символов, иначе поле подсвечивается и форма не уходит.
- Отправка: **JSONP** — запрос уходит тегом `<script>` на `FORM_ENDPOINT`. Так сделано специально: Google не отдаёт CORS-заголовки, и обычный `fetch` не смог бы прочитать ответ (то есть нельзя было бы отличить «сохранилось» от «нет»).
- Адрес принимающей стороны — константа `FORM_ENDPOINT` в самом верху `script.js`.
- Состояния: кнопка «Отправляем…» со спиннером и блокировкой → успех `#formSuccess` (гаснет через 8 секунд) или ошибка `#formError` с телефоном и почтой. Ждём ответ до 20 секунд.
- Вместе с заявкой уходят `source` (метка «Лендинг LILA» + utm, если есть) и `page` (адрес страницы).
- Если `FORM_ENDPOINT` пустой, форма показывает «Спасибо», но **ничего не сохраняет** — в консоли предупреждение. Это режим демонстрации, а не рабочий.
- Заявки пишутся в Google Таблицу, лист «Заявки»: дата, имя, контакт, пожелание, источник, страница, статус (`новая`).
- Контакты на сайте (`+7 921 655-61-81`, `hello@lila-leather.ru`, «ул. Мастеровая, 12») — **вымышленные заглушки**, менять только по подтверждению заказчика.

## Правила работы

1. **Тексты не менять без прямой просьбы.** Формулировки заголовков, цитаты и УТП согласованы дословно — это не черновик для «улучшения».
2. **Структуру блоков не менять без прямой просьбы.** Порядок секций, их состав и якоря (`#problem`, `#contacts` и т. д.) считаются утверждёнными.
3. **Перед большими изменениями — сначала спросить.** К ним относятся: новые секции, удаление или перестановка блоков, смена палитры, шрифтов или общего вида, изменение способа приёма заявок, смена доменов и контактов, переписывание файлов с нуля.
4. Мелкие правки (опечатка, отступ, поведение на телефоне, баг) можно делать сразу, не спрашивая, — и коротко сообщать, что изменил.
5. Ничего не добавлять из внешних источников: **без CDN, без внешних шрифтов, без сторонних библиотек**. Все картинки и шрифты лежат в `assets/`.
6. Держать стиль кода: классы по схеме «блок__элемент--модификатор», цвета и отступы — через переменные `:root`, обычный JS без фреймворков.
7. Не ломать то, что уже работает: появление блоков, параллакс, мини-конструктор, фильтр работ, меню, режим без JavaScript (в `index.html` есть `<noscript>`), доступность (alt, aria-подписи, фокус).
8. Файлы заказчика (`Промпт*.docx`, скриншоты) не трогать: не переименовывать, не удалять, не перезаписывать.
9. Комментарии в коде и любые пояснения — на русском языке.
10. Не менять приём заявок на другой сервис без согласования: связка Google Таблица + Apps Script уже настроена и проверена.

## Как проверить после правок

- Запуск локально: в папке проекта `python -m http.server 5173 --bind 127.0.0.1`, затем открыть <http://127.0.0.1:5173/>.
- Проверить оба режима: узкий экран (375px) и десктоп; горизонтальной прокрутки быть не должно.
- Консоль браузера — без ошибок; картинки и шрифты загружаются.
- Форму отправить по-настоящему и убедиться, что строка появилась в листе «Заявки». Тестовую строку после проверки удалить.
- Правки в `Code.gs` в редакторе Apps Script вступают в силу только после выпуска новой версии: **Развернуть → Управление развёртываниями → ✎ Изменить → Версия: Новая версия → Развернуть**.
